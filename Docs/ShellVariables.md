# 쉘 변수

`A=B`, `A="hello world"`, `A=$HOME`처럼 독립된 대입 명령을 사용할 수 있습니다. 값에서 따옴표 제거와 변수 확장을 수행하되, 변수 확장 결과를 공백으로 분리하지 않습니다. `A=`는 빈 값을 저장합니다. 대입 전 기존 값으로 우변을 확장하고, 성공한 뒤 값을 교체합니다.

변수는 현재 쉘에 저장하며 새 프로그램의 환경에는 자동으로 내보내지 않습니다. `$A` 및 `${A}`는 현재 쉘 변수에서 먼저 찾고, 없으면 환경변수에서 찾습니다. 최대 128개 이름과 각 8191바이트 값을 저장할 수 있으며 실제 값 길이는 기존 파서의 전체 저장 공간 한도에도 제한됩니다. 여러 대입이나 명령 앞 임시 대입, export 및 unset은 지원하지 않습니다.

입력 하이라이팅은 `$`에 `#B76FB7`, 특수 키 `?`·`$`와 사용자 지정 변수 이름에 `#FB530D`, 존재하는 환경변수 이름에 `#F204CF`, 없는 이름에 `#777778`을 사용합니다. `${A}`의 중괄호는 `$`와 같은 색상입니다. 작은따옴표 및 이스케이프한 `$`는 확장으로 표시하지 않습니다.

대입 이름은 `#00AD00`, `=`는 디렉터리 색상 `#0086FF`, 일반 값은 흰색입니다. 값 안의 변수 확장에는 변수 색상 규칙을 적용합니다.

이 변경에 대한 빌드 및 실행 검증은 수행하지 않았습니다.

입력 버퍼는 4096바이트이며 널 종료와 한글 조합을 위한 공간을 예약합니다. 히스토리도 같은 크기를 사용합니다. 입력은 화면 폭에 따라 다음 줄로 이어지고, 이전 입력 영역을 지운 뒤 동기화된 화면 갱신으로 다시 그립니다. 화면 높이를 넘는 입력은 커서 주변 구간을 표시합니다. UTF-8 문자를 중간에서 나누지 않습니다. 줄 배치는 터미널과 동일한 JetBrainsMono/Pretendard 글꼴의 advance 및 글리프 오른쪽 경계를 픽셀 단위로 계산합니다. 글꼴 자산이나 픽셀 크기를 얻지 못한 경우에만 비ASCII 문자를 두 열로 계산하는 방식으로 돌아갑니다. 글꼴 크기와 가로 여백은 Common/Terminal/Text.h에서 공유합니다. 셸은 글리프 이미지를 만들지 않고 측정 결과만 캐시합니다.
