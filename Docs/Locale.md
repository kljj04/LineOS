# 로켈

기본 로켈은 `/etc/locale`에 이름 하나로 저장합니다. 초기 설정은 `en_US.UTF-8`이며 이미지에 설정 파일이 이미 있으면 보존합니다.

```text
locale
locale -a
sudo locale set ko_KR.UTF-8
sudo locale set en_US.UTF-8
```

`locale`은 유효한 현재 로켈을 출력하고, `-a`는 지원 목록을 출력합니다. `set`은 관리자 권한을 확인한 뒤 임시 파일을 기록하고 이름을 변경하여 설정을 교체합니다. 지원 이름은 `C`, `C.UTF-8`, `en_US.UTF-8`, `ko_KR.UTF-8`입니다. `POSIX`는 `C`의 별칭으로 허용합니다.

libc의 `setlocale(LC_ALL, "")`는 `LC_ALL`, 해당 `LC_*`, `LANG`, `/etc/locale`, `C` 순서로 설정을 선택합니다. 설정 파일이 없거나 잘못되었으면 `C`로 돌아갑니다. 잘못된 환경변수나 명시적으로 지정한 지원하지 않는 이름은 실패하며, 기존 로켈을 유지합니다. 프로그램은 초기화할 때 `setlocale`을 호출하여 설정을 적용합니다.

lsh는 매 프롬프트에서 설정을 다시 읽습니다. 따라서 `locale set`을 실행한 쉘은 다음 프롬프트부터 변경을 적용합니다. 환경변수가 지정되어 있으면 파일 설정보다 우선합니다. 다른 실행 중인 프로그램의 설정은 자동으로 변경하지 않습니다.

날짜와 시간대는 독립적입니다. `/etc/timezone`은 시간대를 선택하고 `LC_TIME`은 날짜의 표시 형식을 선택합니다. `date`와 `ls -l`이 이 형식을 사용합니다. 소수점은 `.`이며 숫자 구분은 적용하지 않습니다.

현재 범위는 기본 로켈 선택, `localeconv`, 주요 `strftime` 형식, lsh 문구, 주요 errno의 `strerror` 및 `perror`입니다. 전체 프로그램 번역, 번역 파일 로딩, Unicode 정렬 및 문자 분류, 전체 POSIX 로켈 구현은 포함하지 않습니다. `strftime`은 요일·월 이름, 연월일, 시분초, 시간대, 복합 날짜와 기본 자릿수 플래그를 지원하며 지원하지 않는 형식은 0을 반환합니다. ISO 주 번호 및 GNU 확장 전체는 지원하지 않습니다.

lsh의 시스템 오류는 표준 오류로 출력합니다. 빈 입력의 Ctrl+D 또는 입력 EOF는 경로 색상 `#0086FF`의 `[lsh: EOF]`를 표시합니다. `exit` 및 로그인 쉘의 `logout`은 빌틴 색상 `#D67A7A`의 `[lsh: exit n]`을 표시합니다. 상태 생략 시 마지막 명령의 상태를 사용하며, 숫자를 지정하면 하위 8비트를 사용합니다. 자식 쉘의 `logout`은 거부합니다.

이 변경에 대한 빌드 및 실행 검증은 수행하지 않았습니다.

lsh는 외부 명령 및 빌틴의 상태가 0이 아니면 빌틴 색상의 `[lsh: exit n]`을 표시합니다. 성공한 일반 명령에는 표시하지 않습니다. 외부 명령은 부모 쉘이 waitpid로 결과를 수집한 후 알림을 표시하므로, 커널의 `exit: pid=... code=...` 로그가 먼저 기록될 수 있습니다.

## 메시지 API

프로그램은 시작할 때 `setlocale(LC_ALL, "")`를 호출합니다. 실패하면 `setlocale(LC_ALL, "C")`로 기본값을 적용합니다. 사용자 안내 문구는 `<libintl.h>`의 `gettext`를 사용합니다.

```c
puts(gettext("Usage: cat [FILE ...]"));
printf(gettext("[sudo] password for %s: "), Username);
```

`LOSLibC/Source/Locale/gettext.c`의 내장 번역표에 영어 원문과 한국어 문구를 등록합니다. 표는 영어 원문 기준 strcmp 순서를 유지합니다. `LC_MESSAGES`가 `ko_KR.UTF-8`이면 한국어를 반환하고, 그 외 로켈이거나 번역이 없으면 원문을 반환합니다. 서식 인자의 개수와 타입은 원문과 동일해야 합니다. 외부 `.mo` 파일, 번역 도메인 및 복수형 API는 아직 지원하지 않습니다.

셸 명령, 계정 관리 명령, 로그인 및 복구 안내가 이 API를 사용합니다. sudo는 전체 환경을 복사하지 않고, 현재 적용된 여섯 로켈 카테고리만 생성한 관리자 환경에 추가합니다. btop의 상태명은 한글 표시 폭을 반영하여 열을 맞춥니다. 숫자·CPU·PID 등 공통 단위와 식별자는 그대로 표시합니다.
